🚀 Quick Start - Run in Eclipse

1 Open Eclipse IDE

Launch your Eclipse IDE for Java EE Developers

2 Project Should Already Be There

Check Project Explorer - "University ERP" should be visible

ℹ️
Already Imported!
Your project is already in the workspace at:
C:\Users\HP\eclipse-workspace\University ERP
3 Configure Tomcat Server (One Time Setup)

Only if not configured already:

  • Go to: Window → Preferences → Server → Runtime Environments
  • Click "Add" button
  • Select "Apache Tomcat v9.0"
  • Browse to your Tomcat installation directory
  • Click "Apply and Close"
4 Run the Project

Follow these exact steps:

  • Right-click on "University ERP" project in Project Explorer
  • Select "Run As" → "Run on Server"
  • Select "Tomcat v9.0 Server at localhost"
  • Click "Finish"
✅
Success!
Server will start and browser will auto-open with the application
5 Access the Application

If browser doesn't auto-open, manually go to:

http://localhost:8080/University_ERP/

Or directly access login:

http://localhost:8080/University_ERP/login.jsp

🔧 Troubleshooting

Problem: Port 8080 already in use

Solution: Stop other applications using port 8080 or change Tomcat port in server.xml

Problem: 404 Error - Page Not Found

Solution:

  • Check URL spelling: Should be "University_ERP" (with underscore)
  • Ensure project is deployed: Check Servers tab in Eclipse
  • Clean and rebuild project: Project → Clean

Problem: CSS/JS not loading properly

Solution:

  • Hard refresh browser: Press Ctrl + F5
  • Clear browser cache
  • Check browser console for errors (F12)

Problem: Server won't start

Solution:

  • Stop server: Click red square in Servers tab
  • Clean Tomcat work directory
  • Remove and re-add project to server
  • Restart Eclipse

Problem: Changes not reflecting

Solution:

  • Stop server
  • Clean project: Project → Clean
  • Restart server
  • Hard refresh browser (Ctrl + F5)
